College Examination Schedule Management System Using Linked List in C++

Introduction

The College Examination Schedule Management System is a C++ project that uses a Singly Linked List to store and display examination details, including subject names and examination dates , exam id , Hall number.

Problem Statement

Managing examination schedules manually can be difficult and time-consuming. This project provides a simple way to store and display examination records using a linked list.

Objectives

1. To implement a Singly Linked List in C++.
2.To store examination details dynamically.
3. To display the examination schedule.
4. To understand pointers and dynamic memory allocation.

6. Advantages

1. Dynamic memory allocation.
2. Easy to insert new examination records.
3. No fixed-size array is required.
4. Simple and easy to understand.

Disadvantages

1. Requires extra memory for pointers.
2. Traversing the list takes time.
3. Direct access to a particular record is not possible.

Limitations

1. Records are not permanently stored unless file handling is implemented.
2. Automatic examination clash detection is not available.
3. Search, update, and delete operations are not included in the basic version.

Conclusion

This project demonstrates the use of a Singly Linked List in C++ to manage examination records. It helps in understanding dynamic memory allocation, pointers, and linked-list operations.
